NIKHILA'S BIRTHDAY WEBSITE
==========================

FILES
- index.html        The complete website (HTML, CSS and JavaScript)
- assets/           The five photos used by the website

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. Internet is only needed for the optional Google Fonts import; the website itself works without it.

EDIT THE WORDING OR PHOTOS
- Open index.html in any text editor to change the messages.
- Replace photos inside assets/ while keeping the same filenames, or change the image paths in index.html.
- The "hood-selfie.jpg" is the opening birthday photo.
- "proud-indian.jpg" is used for the Indian-flag moment.
- The two middle photos are used in the movie-night section.
- "goofy-closeup.jpg" is used for the final sticker-style joke.

PUBLISH FOR A SHAREABLE URL (FREE)
NETLIFY DROP:
1. Go to https://app.netlify.com/drop
2. Sign in or create a free Netlify account.
3. Drag the extracted nikhila_birthday_website folder onto the page.
4. Netlify will publish it and provide a public URL you can share.

VERCEL:
1. Create a GitHub repository and upload the contents of this folder.
2. Import that repository at https://vercel.com/new
3. Deploy using the default settings (no build command needed).
4. Share the generated URL.

NOTES
- This is a two-screen experience: an opening surprise screen followed by one scrollable birthday page.
- Confetti and all buttons work without extra libraries.
- No music is included, so there is no autoplay or copyright issue. You can add your own licensed audio later if you want.
- Check the photos and wording once before publishing, especially the joke captions, to make sure they match your friendship.
